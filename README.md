# 🌸 Wrapped.inn — Gifts & Special Collections

**Wrapped.inn** is a creative and elegant website for a gifting brand that offers curated and handcrafted gifts, trousseau wrapping, and personalized collections.  
Designed with a clean, mobile-friendly layout and smooth user experience.

---

## 🖼️ Project Overview

The website showcases various product categories, integrates a hero slideshow, and includes essential features like:
- Product collections with prices and discount badges  
- A responsive grid layout  
- Smooth hover animations  
- Contact and cart navigation  
- A modal popup for **Terms & Conditions**

## ⚙️ Features

### 🏠 Homepage
- Clean, minimal layout built using **HTML & CSS**
- Animated **image slideshow** at the top
- Responsive **4-column product grid** (2 columns on mobile)
- Hover zoom and shadow effect on product cards

### 🛒 Product Cards
Each card includes:
- Image preview  
- Product name  
- Original and discounted price  
- “% OFF” badge  
- Redirects to a dedicated product page

### 📞 Navigation Icons
Top-right quick icons:
- 🛒 — Cart  
- 📞 — Contact  
- 🗒 — Special Request

### 📄 Terms & Conditions Modal
- Opens in a pop-up box without leaving the page  
- Scrollable and mobile-friendly  
- Easy to close by clicking the “×” or outside the box  

### 📱 Fully Responsive
Optimized for:
- Mobile screens (≤720px)
- Tablets and desktops
- Uses CSS grid and flexbox for adaptive layouts

---

## 💡 Technologies Used

- **HTML5** for structure  
- **CSS3** for design and responsiveness  
- **Vanilla JavaScript** for slideshow and modal interactions  
- **SVG Icons** for clean scalable visuals
